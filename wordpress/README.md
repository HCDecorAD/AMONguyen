# WordPress source (LocalWP: amo-factory-staging)

Chỉ chứa code tuỳ biến: plugin `hc-amo-lang` và các file chính của theme `shoes-store-elementor` (theme gốc GPL, đã chỉnh sửa).
Không chứa: `wp-config.php`, database, `uploads`, plugin/theme của bên thứ ba (WooCommerce, Elementor, Astra...).
Ảnh/font/css thư viện của theme không đưa vào; khi dựng lại site, cài theme gốc rồi chép đè các file ở đây.
